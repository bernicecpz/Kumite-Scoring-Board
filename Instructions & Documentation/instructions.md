# Starting the program
Open KumiteScoreDashboard.html in a web browser (preferrably Chrome) to start using the program.

# Controls
- To start/stop timer, you can do so by:
  - Click on the timer box
  - Press "Enter" on the keyboard (Preferred)

- To award points
  - Click on the blue/red area respectively
  - If points are wrongly awarded, click on the box with the "minus" sign

- To give fouls, click on the respective fouls as given by referee
  - Category 1 for contact fouls, Category 2 for non-contact fouls
  - Chukoku (C) : First Warning
  - Keikoku (K) : Second Warning
  - Hansoku (HC) : Third Warning

- To set/ reset timer
  - Press the numbers (1,2 or 3) to set 1 min, 2 min or 3 min
  - Press "S" to add 30 seconds to the timer

- Shortcut key & Description:
  - S: Add 30 seconds to timer
  - Esc: To reset all values to initial stage
